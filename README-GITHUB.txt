FITGO - PAQUETE PARA GITHUB PAGES

Archivos que debes subir al repositorio:
- index.html
- assets/
- .nojekyll
- README-GITHUB.txt

Pasos recomendados:
1. Crea un repositorio nuevo en GitHub, por ejemplo: fitgo-web.
2. Entra al repositorio y usa "Add file" > "Upload files".
3. Sube index.html, la carpeta assets completa, .nojekyll y este README.
4. Presiona "Commit changes".
5. Entra a Settings > Pages.
6. En Source elige "Deploy from a branch".
7. En Branch elige main y carpeta /root.
8. Guarda.

GitHub publicara tu sitio en una direccion parecida a:
https://TU-USUARIO.github.io/fitgo-web/

Importante:
- No cambies los nombres de carpetas ni archivos.
- La carpeta assets debe quedar en la raiz del repositorio, al mismo nivel que index.html.
- GitHub diferencia mayusculas y minusculas, por eso conviene subir el paquete tal como esta.
